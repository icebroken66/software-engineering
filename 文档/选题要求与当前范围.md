# 选题要求与当前范围

对应选题二：面向学生和知识工作者的本地优先 Markdown 笔记工具。

| 初步要求 | 当前范围 | 验证边界 |
| --- | --- | --- |
| Markdown 编辑 | 源码/分屏/预览、格式工具栏、自动与手动保存 | 单元与浏览器检查；原生异常场景仍待完整回归 |
| 标签 | 平级标签增删、计数与筛选 | 真实 SQLite 测试及模拟界面检查；不含层级标签 |
| 全文检索 | 笔记标题和正文的整段关键词匹配，可结合标签/分类 | 支持中文子串，不宣称中文分词、复杂语法或十万篇性能 |
| 双链引用 | 双括号跳转、反向链接、创建不存在目标 | 底层索引和界面检查；原生完整操作待回归 |
| 导出 | 单篇 Markdown 导出 | 导出前等待保存；系统对话框取消/异常仍需手动检查 |
| 同步策略 | 本轮采用单机本地库，不做多端同步 | 不得宣称已支持云同步 |
| 备份策略 | 默认 Markdown 镜像；关闭程序后手动复制完整运行数据目录 | 镜像不能代替整库备份；当前无完善的自动快照/恢复界面 |
| 插件/主题 | 浅色与深色主题；不开放插件扩展 | 主题可记忆，插件不纳入本轮 |
| 移动端 | 不纳入，Windows 桌面版 | 需要已安装 WebView2 |
| 协作 | 不纳入，个人单机使用 | 不支持多人共享编辑 |

按初步选题，核心方向与功能范围基本吻合；不能据此声称原实验一/二的155条详细基线全部实现。原72条功能对照随源码的 course-docs/当前演示版与任务书对照.md 提供，缺项未被隐去。
